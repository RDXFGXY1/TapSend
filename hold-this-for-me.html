Hold This for Me

Bring back a file or Paste Stack item when you need it

Hold a Paste Stack item or a reference to a file until you return to the right place.

Hold a screenshot or text

  1. In Files, open the folder you want to return to, or choose a paired phone with V.
  2. Press Shift+V to open Paste Stack and select the item.
  3. Press H to hold the item until you revisit that folder, or J to hold it until the selected phone reconnects.

Hold a file

In Files, focus the file and press Shift+H. When you return to this folder, its reference becomes available in Paste Stack. Keep the original file in place if you want to copy it later.

Held items remain across restarts. Press B inside Paste Stack to bring back every held item immediately.
