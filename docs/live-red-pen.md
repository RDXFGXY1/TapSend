# Live Red Pen

Send a temporary arrow to a phone while it shares its screen. The phone chooses whether to allow arrows for that session.

1. On Windows, open Screen Share for the paired phone.
2. On Android, choose **Tools → Share screen with Live Red Pen**. If Settings opens, allow TapSend to **Display over other apps**, return to TapSend, and select the same Tools action again.
3. Accept Android's full-screen capture prompt.
4. Right-drag with the mouse in the live Windows viewer. Release to send the arrow to the phone. It disappears automatically.

Choose **Share screen to PC** on Android for an ordinary session with annotations off. Stop the screen share to end both the stream and annotations.
