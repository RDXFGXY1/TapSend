# Throw to This Folder

Use a folder on Windows as a temporary destination for one paired phone.

1. Press **V** and select the phone.
2. Press **F**, navigate into the destination folder, and press **Shift+R**.
3. On Android, send a file from TapSend or use Android's **Share → TapSend** flow.
4. Review the displayed Windows folder. Choose **Send here** to use it, **Use inbox** for the default location, or **Cancel**.

The drop stays available for ten minutes. If it changes or expires before Android starts an upload, choose the destination again. Files that arrive with an existing name receive a numbered suffix such as `report (2).pdf`, and the Android result shows the saved name.
