# Freeze & Grab

1. Open a live [Screen Share](screen-share.md) session.
2. Press **Space** in the Windows viewer to freeze the displayed frame.
3. Drag with the left mouse button to select an area. With no drag selection, the grab uses the full captured frame.
4. Press **G** to save an image or **T** to read the text with Windows text recognition.
5. In the main TapSend window, press **Shift+V** to open Paste Stack. Select the result and press **Enter** to copy it.

Press **Space** again in the viewer to return to the live stream. For text recognition, install Windows OCR support for the language on the screen and select a larger, clearer area if words are missed.
