# TapSend features

| Feature | Where it works |
| --- | --- |
| Pair by QR, pass, link, or manual details | Windows desktop and Android. The terminal app and browser also support the pairing methods their interfaces display. |
| Send and receive files | Computer ↔ Android app or phone browser |
| Send to a selected phone, track progress, and confirm saves | Windows send queue and the targeted-send CLI |
| Send Later | Windows keeps targeted offers for paired phones across desktop restarts |
| Portal Mode | Local computer browser for the QR and arrival feed, plus Android or phone browser for uploading |
| Nearby share | An Android phone hosts a share that a second phone can open in TapSend or its browser |
| Search and mark files | **Shift+S** in the Windows desktop app |
| Background receiving and Explorer **Send to** | Windows desktop |
| Resume eligible downloads | Android app and the phone browser |
| Messages and Scratchpad | Windows and supported Android and browser clients |
| Paste Stack | Android Share for incoming screenshots and text, Windows to copy them |
| Screen Share, Freeze & Grab, and Live Red Pen | Android capture and Windows viewer |
| Throw to This Folder | A folder selected on Windows and confirmed when sending from Android |
| Hold This for Me | Windows file browser and Paste Stack |
| File Relay | Windows sender and destination, with a shared folder on a third computer |

Linux provides the terminal file browser and core pairing and transfer tools. For Windows-only commands, use the standalone `TapSend-Desktop.exe`. See the [documentation index](README.md) for individual guides.
