# Quick start

## Install

- **Windows.** Quit TapSend in the tray if it is already open. Run the installer to choose the program location, inbox, private storage, and upload limit. For portable use, extract the complete ZIP, open `TapSend-Desktop.exe`, and complete First-Run Setup if prompted.
- **Android.** Install the matching APK on Android 13 or newer. Android can update an installed copy in place when the packages have matching signatures.
- **Linux.** Extract the Linux archive and run `bin/tapsend` from a terminal. See the [terminal guide](tui-2.md) for its controls.
- **Phone browser.** Open the computer's pairing link. Follow [browser setup](browser.md) if the browser warns about TapSend's local certificate.

See [Releases and downloads](releases.md) for the correct package.

## Pair a phone with Windows

1. Connect both devices to the same local network and open TapSend on Windows. The desktop app starts its server after first-run setup is complete.
2. Press **P** on Windows to show the pairing QR.
3. On Android, open **Tools → Connect a PC**, optionally set a device name, and choose **Scan QR**.
4. If the phone asks for approval, press **V** on Windows, highlight its request, and press **A**.

For camera-free setup, copy the pairing pass with **Y** on the Windows pairing screen. See [Pairing and devices](pairing.md).

## Send your first file

**Windows to Android**

1. Press **V**, highlight your phone, and press **Enter**.
2. Press **F**, open the file's folder, and mark the file with **Space**. Press **S** to send the offer.
3. Open TapSend on Android and accept the offer. Watch the desktop queue for the save confirmation.

**Android to Windows**

1. In TapSend on Android, select **Computer → Send files**, then pick the files and send the queue. You can also choose **TapSend** from Android's Share menu.
2. When the phone reports **Saved on computer**, find the file in your computer inbox. Press **R** on Windows for the Receive view or check **G → Computer inbox** for its location.

Press **N** on Windows for shortcut help. See [Sending and receiving files](transfers.md) for more transfer options.
