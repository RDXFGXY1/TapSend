# Paste Stack

## Add items from Android

1. Share a screenshot or text from another Android app.
2. Choose **TapSend → Add to Paste Stack**.
3. TapSend queues the item on the phone if the paired PC is offline and retries in the background. Reopen TapSend if Android has delayed background delivery.

## Copy items on Windows

Press **Shift+V**, select an item with the arrows, and press **Enter** to copy it. Paste in the app you were using with **Ctrl+V**. Press **U** or **D** to move items up or down, or **X** to move one to the end. The queue and its order persist across desktop restarts.

Screen Share grabs also appear here. For items you only want to see when you reopen a folder or reconnect a phone, use [Hold This for Me](hold-this-for-me.md).
