Download recovery

Resume a computer-to-phone download after closing the app or page

TapSend can reuse parts of an interrupted computer-to-phone download in current Android and browser builds.

Resume a download

  1. Reconnect to the same computer.
  2. Reopen TapSend on Android or return to the same browser profile and TapSend address.
  3. Open the same shared file and tap Retry or Download. On supported browser downloads, the progress display can show the amount restored.

TapSend matches saved chunks to the file revision. If the computer changes the file, share the new version and start a new download. Android keeps partial downloads in app storage. The browser uses its site storage, which can be cleared or limited by browser policy, private sessions, or low space. A different browser profile or a different TapSend address can use separate storage.

Recovery covers supported downloads from the computer. If an upload from the phone fails, send that upload again.
